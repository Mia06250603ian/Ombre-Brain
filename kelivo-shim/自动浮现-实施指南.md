# 自动浮现:她每句话前,先从记忆库翻一件相关的旧事给 AI —— 实施指南

> 写给**同款架构**的朋友(或者替朋友干活的 Claude Code)。
> 原型于 2026-09-30 在一套线上系统实装:上线前拿真实记忆库只读彩排过,当晚又按真实消息收紧了三处,之后一直开着。
> **适用前提**:记忆库是 **Ombre-Brain**(Python / FastMCP,记忆 = 带 YAML 头的 Markdown「桶」,每个桶有 `tags`);
> 前面有一个 **shim**,它常驻一个 `claude -p` 进程当 AI 本体,前端(Kelivo / Telegram 桥 / 网页……)经它的 `/v1/messages` 说话。
> 结构不同的话,第 1 节的原理和第 5 节的坑照样通用,代码要自己改。
>
> 文中所有地址、密钥、称呼都是占位符(`<OB域名>`、`<随机长串>`、`<她的名字>`……)。
> **先读第 5 节「坑」再动手** —— 第一版就是照「看起来很合理」的写法写的,一上真实库就翻车。
>
> 思路借鉴 [Latent-memory](https://github.com/Mia06250603ian/Latent-memory) 的 Passive Recall。**只借了思路,代码是自己写的**
> (那边的许可证不许分发);下面的代码可以随便抄。

## 0. 解决的是什么问题

**以前**:AI 只有在**自己想起来**去调 `breath(query=…)` 时才会翻记忆。她随口提一句「鼻炎又犯了」,
他多半不会停下来先搜一下 —— 于是明明记忆库里存着「上个月她鼻炎、我们聊过用哪个喷雾」,他接的话却像第一次听说。

**做完之后**:她每发一句,shim 先拿这句话去问记忆库「有没有一件**确实相关**的旧事」。有,就在这句话前面悄悄加一行
(只有 AI 看得见):

```
【系统·浮现】记忆库里自动翻到一件可能相关的旧事(系统附的,不是她说的;用得上就自然接住,用不上就当没看见;别提这行标注):2026-08-14 「她的鼻炎」上个月她换季鼻炎犯了……(全文:dream(detail_ids="a1b2c3d4e5f6"))
```

没有就什么都不加。**绝大多数闲聊都应该空手** —— 这是设计目标,不是故障。

**她那边看不到任何变化**(不多一条消息、不慢多少),只是他「记性变好了」。

## 1. 原理(四条规矩)

整件事拆成两半:**挑哪一件**在记忆库(OB)里做,**要不要问、怎么递**在 shim 里做。中间一个只读的 HTTP 口子:

```
她的消息 → shim ──GET /api/recall?q=她那句话──▶ OB
                 ◀── {pick: 一件旧事 | null}
          shim 有就在那句前加一行【系统·浮现】,再交给常驻进程
```

### 1.1 只读

问一次**不能改任何东西**:不涨 `activation_count`、不刷新 `last_active`、不触发时间涟漪。
自动递上去的不算「他想起来了」;要是算,被递过一次的桶权重就涨一点 → 更容易再被递 → **滚雪球**,
最后每句话都翻出同一件事。Ombre-Brain 的 `bucket_manager.search()` 本来就不 touch,别在新接口里补调 `touch`。

### 1.2 宁可空手

她大部分话是闲聊。**附错一件比不附更伤**:他会以为她在提那件事,话就接歪了。拿不准一律不附。
所以**每句最多递一件**,而且有一道很硬的门槛(下一条)。

### 1.3 只信「稀有词」

Ombre-Brain 的关键词检索是子串匹配:「今天好开心」会撞上所有带「开心」标签的桶。所以 OB 的检索结果**只当候选**,
真正放行要求:**这个桶的某个标签原样出现在她这句话里,而且这个词在全库不常见**。

「不常见」= 全库里**名字 / 正文 / 标签中出现过这个词**的记忆 ≤ max(3, 桶数 × 5%) 条。
- 「鼻炎」「海边」「螃蟹」这种具体的事 → 只在几条记忆里出现 → 放行;
- 「开心」「我们」「记忆」这种到处都是的词 → 几十上百条 → 挡住。

⚠️ **数的是正文,不是标签**。这是第一版翻车的地方,见第 5 节坑 1。

### 1.4 shim 那半:不打扰、不乱序、有上限

- **三档开关**:`off`(不设就是它,代码路径和没这功能时逐字相同)/ `observe`(问、记日志,**不递**)/ `on`(真递)。
  **运行时能改档,不重启、不丢窗口**。
- **等不到就算了**:等 OB 最多 1.5 秒,超时 / 出错一律照常发、不附。
- **不乱序**:等 OB 的那一两秒里,她紧接着发的「嗯」不能插到前面去。
- **有上限**:递进去的那行**永久留在 AI 的窗口里**(跟时间、天气注入一样进了会话历史),所以同一件 12 小时内不重复递,
  每个窗口最多递 30 次。

```python
# recall.py — 「自动浮现」的挑选逻辑。入口是 server.py 的 GET /api/recall。
# 三条硬规矩:①只读(不 touch);②宁可空手;③只信「稀有词」(按全库正文出现次数算,不按标签数)。
# 几件都合格时,先挑桶名和她这句话最贴的那件,再看分数。

from __future__ import annotations

import math
import re
from datetime import datetime, timedelta

# 稀有词的门槛:出现在 ≤ max(RARE_MIN, 全库桶数 × RARE_RATIO) 条记忆里。
# 原型(410 条)上 5% = 21:声音 22 / 第一次 30 / 吃饭 44 / 开心 50 / 我们 119 被挡;海边 5 / 鼻炎 10 / 纪念日 12 / 吵架 14 放行。
RARE_MIN = 3
RARE_RATIO = 0.05
MIN_TAG_LEN = 2

# 永远不算「具体的事」的词。光按出现次数分不开:原型库里「委屈」16、「想你」14,和「代码」14、「纪念日」14 一个量级。
# 情绪词 / 称呼 / 口头语出现在她大半的话里,拿它们去翻,翻出来的只会是「另一次她也委屈了」。
# 系统词是她跟 AI 聊这套系统本身时说的,翻出来的是维护记录,不是共同经历。
STOP_WORDS = {
    # 情绪
    "开心", "高兴", "快乐", "难过", "伤心", "委屈", "难受", "生气", "气死", "烦", "烦死", "焦虑", "害怕", "紧张",
    "心疼", "吃醋", "撒娇", "想你", "想念", "思念", "喜欢", "爱你", "抱抱", "亲亲", "哭", "哭哭", "笑死",
    "孤单", "寂寞", "累", "好累", "无聊", "开心果", "幸福", "安全感", "温暖", "失落", "崩溃", "感动", "担心",
    # 称呼 —— ⚠️ 换成你们自己的
    "老公", "老婆", "宝宝", "宝贝", "<她的名字>", "<AI的名字>", "你", "我", "我们", "她",
    # 聊天口头语
    "晚安", "早安", "早上好", "在吗", "回来", "到家", "吃饭", "睡觉", "起床", "洗澡", "说话", "聊天", "第一次",
    "今天", "昨天", "明天", "现在", "刚才", "一起", "日常", "记忆", "声音", "消息",
    # 系统 / 工具
    "awaken", "breath", "hold", "trace", "dream", "pulse", "grow", "archive", "ob", "记忆库", "归档", "窗口",
    "压缩", "上下文", "系统", "claude", "模型", "session", "对话归档", "贴纸", "表情包", "语音", "图片",
}

# 繁 → 简:语音转写常把普通话输出成繁体(「海邊」),记忆库是简体,子串一个都对不上。
# 用 opencc-python-reimplemented(Apache-2.0)。别用 zhconv(GPL)。包缺了就原样返回,不报错。
try:
    from opencc import OpenCC as _OpenCC
    _T2S = _OpenCC("t2s")
except Exception:
    _T2S = None


def to_simplified(text: str) -> str:
    if not text or _T2S is None:
        return text or ""
    try:
        return _T2S.convert(text)
    except Exception:
        return text


def clean_query(text: str) -> str:
    """去掉桥自动写的那部分,只留她真说的话。
    - 「(她发来一个贴纸)」「(她发来一张图片…)」这类括号句是桥写的,整段去掉;
    - 语音转写 `[语音] 她说的话(语气:…)`:话留下,语气分析去掉。
    括号冒号半角全角都认。⚠️ 你的桥写的格式不一样就照着改这里。"""
    L, R, C = "[\\(（]", "[\\)）]", "[:：]"
    t = text or ""
    t = re.sub(L + "她[^()（）]*" + R, " ", t)
    t = re.sub(r"\[语音\]\s*", " ", t)
    t = re.sub(L + "语气(?:" + C + "|分析)[^()（）]*" + R, " ", t)
    return to_simplified(re.sub(r"\s+", " ", t).strip())


class WordDF:
    """一个词在全库多少条记忆里出现过(名字 + 正文 + 标签,不分大小写)。按需算、缓存。"""
    def __init__(self, buckets: list[dict]):
        self.docs = []
        for b in buckets:
            meta = b.get("metadata", {})
            tags = " ".join(str(t) for t in (meta.get("tags") or []))
            self.docs.append(f"{meta.get('name', '')} {b.get('content', '')} {tags}".lower())
        self._cache: dict = {}

    def get(self, word: str, default: int = 0) -> int:
        w = (word or "").lower()
        if w not in self._cache:
            self._cache[w] = sum(1 for d in self.docs if w in d)
        return self._cache[w]


def rare_limit(n_buckets: int) -> int:
    return max(RARE_MIN, math.ceil(n_buckets * RARE_RATIO))


def rare_tags_in(query: str, tags: list, df, limit: int) -> list[str]:
    """这个桶的标签里,哪些原样出现在她这句话里、且在全库不常见。"""
    q = (query or "").lower()
    hits = []
    for t in tags or []:
        t = str(t).strip().lower()
        if len(t) >= MIN_TAG_LEN and t not in STOP_WORDS and t in q and df.get(t, 0) <= limit:
            hits.append(t)
    return hits


def _parse_dt(raw) -> datetime | None:
    try:
        return datetime.fromisoformat(str(raw).replace("Z", "+00:00")).replace(tzinfo=None)
    except (ValueError, TypeError):
        return None


def excerpt(content: str, max_chars: int) -> str:
    """取开头 max_chars 字;能在句号处断就在句号处断。"""
    text = re.sub(r"\s+", " ", content or "").strip()
    if len(text) <= max_chars:
        return text
    cut = text[:max_chars]
    stop = max(cut.rfind(p) for p in "。!?!?;;")
    if stop >= max_chars * 0.5:
        return cut[: stop + 1]
    return cut + "…"


def excluded_reason(meta: dict, now: datetime, min_age_hours: float, is_expired=None) -> str:
    """不该自动递的桶返回原因,该递返回空串。"""
    if meta.get("pinned") or meta.get("protected"):
        return "pinned"       # 钉选的 awaken 每次都带全文,再递是重复
    if meta.get("type") == "feel":
        return "feel"         # AI 自己的感受,不当「旧事」递
    if meta.get("dormant"):
        return "dormant"
    if int(meta.get("denied", 0) or 0) > 0:
        return "denied"       # 她否认过的(你的 OB 没有否认功能就删掉这两行)
    if is_expired and is_expired(meta):
        return "expired"
    created = _parse_dt(meta.get("created"))
    if created and now - created < timedelta(hours=min_age_hours):
        return "too_new"      # 刚存的多半还在这个窗口里,递了是复读
    return ""


def name_overlap(query: str, name: str, rare: list[str]) -> int:
    """桶名和她这句话共有的最长一段字有多长 —— 只算包含某个命中稀有词的那段。
    几件都合格时靠它挑最贴的那件(见第 5 节坑 12)。只认含稀有词的段,免得称呼这种到处都是的字给桶名白加分。"""
    q, n = (query or "").lower(), (name or "").lower()
    best = 0
    for r in rare or ():
        start = n.find(r)
        while start != -1:
            for i in range(start, -1, -1):
                for j in range(len(n), start + len(r) - 1, -1):
                    if j - i <= best:
                        break
                    if n[i:j] in q:
                        best = j - i
                        break
            start = n.find(r, start + 1)
    return best


def pick(query, matches, all_buckets, now, min_age_hours=24, max_chars=240, exclude_ids=(), is_expired=None) -> dict:
    """从 search() 的结果里挑最多一条。返回 {"pick": {...} | None, "reason": str, "candidates": [...]}。
    candidates 是前三条及各自为什么没选上,给 shim 的观察记录用,不含正文。"""
    df = WordDF(all_buckets)
    limit = rare_limit(len(all_buckets))
    exclude = set(exclude_ids or ())
    candidates, eligible = [], []
    for b in matches:
        meta = b.get("metadata", {})
        why = excluded_reason(meta, now, min_age_hours, is_expired)
        rare = rare_tags_in(query, meta.get("tags", []), df, limit)
        if not why and b["id"] in exclude:
            why = "cooldown"
        if not why and not rare:
            why = "no_rare_word"
        overlap = name_overlap(query, meta.get("name", ""), rare) if not why else 0
        if len(candidates) < 3:
            candidates.append({"id": b["id"], "name": meta.get("name", b["id"]),
                               "score": b.get("score", 0), "rare": rare, "overlap": overlap, "skip": why})
        if not why:
            eligible.append((overlap, len(eligible), b, rare))
    if not eligible:
        return {"pick": None, "reason": "empty" if not matches else "no_trusted_hit", "candidates": candidates}
    # 合格的里面:先比桶名跟她这句话重合多少,一样再按 search() 原来的顺序
    _, _, b, rare = max(eligible, key=lambda e: (e[0], -e[1]))
    meta = b.get("metadata", {})
    return {
        "pick": {"id": b["id"], "name": meta.get("name", b["id"]), "created": str(meta.get("created", ""))[:10],
                 "score": b.get("score", 0), "rare": rare, "excerpt": excerpt(b.get("content", ""), max_chars)},
        "reason": "ok",
        "candidates": candidates,
    }
```

### 2.2 OB:接口 `GET /api/recall`(加进 `server.py`)

```python
@mcp.custom_route("/api/recall", methods=["GET"])
async def api_recall(request):
    from starlette.responses import JSONResponse
    import recall as _recall
    token = os.environ.get("OMBRE_RECALL_TOKEN", "").strip()
    if not token:                                   # 不设 = 口子关着
        return JSONResponse({"error": "recall disabled"}, status_code=404)
    auth = request.headers.get("authorization", "")
    given = auth[7:].strip() if auth.lower().startswith("bearer ") else ""
    if not given or not hmac.compare_digest(given, token):
        return JSONResponse({"error": "Unauthorized"}, status_code=401)
    query = _recall.clean_query((request.query_params.get("q", "") or "")[:2000])
    if len(query) < 2:
        return JSONResponse({"pick": None, "reason": "empty_query", "candidates": []})

    def _num(name, default, lo, hi):
        try:
            return max(lo, min(hi, float(request.query_params.get(name, default))))
        except (TypeError, ValueError):
            return default

    max_chars = int(_num("n", 240, 60, 800))
    min_age = _num("min_age_hours", 24, 0, 24 * 30)
    exclude = [x for x in request.query_params.get("exclude", "").split(",") if x.strip()]
    try:
        all_buckets = await bucket_mgr.list_all(include_archive=False)
        matches = await bucket_mgr.search(query, limit=20, use_embedding=False, all_buckets=all_buckets)
        for b in matches:
            b["content"] = strip_wikilinks(b.get("content", ""))
        return JSONResponse(_recall.pick(query, matches, all_buckets, datetime.now(),
                                         min_age_hours=min_age, max_chars=max_chars,
                                         exclude_ids=exclude, is_expired=_is_expired))
    except Exception as e:
        logger.warning(f"recall failed: {e}")
        return JSONResponse({"error": str(e)}, status_code=500)
```

**要给 `bucket_manager.search()` 加两个可选参数**(默认值 = 原行为,`breath` 不受影响):
- `use_embedding: bool = True` —— 传 `False` 时跳过向量预筛。自动浮现只认原话里的稀有标签,向量用不上;
  不跳的话**她每句话都多调一次 embedding API**,又慢又吃额度。
- `all_buckets: list[dict] = None` —— 调用方已经读过全库就传进来,别再 `list_all` 一遍。

你的 OB 没有 `_is_expired`(过期)或 `strip_wikilinks` 的话,`is_expired=None`、去掉那个循环即可。

### 2.3 shim:纯逻辑 `recall.mjs`(零依赖)

```js
export function recallMode(v) {
  const s = String(v || "").trim().toLowerCase();
  return s === "on" || s === "observe" ? s : "off";
}

// 这句该不该去问 OB。返回空串 = 该问;否则是不问的原因。
export function skipReason({ mode, configured, text, reset, systemTurn, windowCount, windowMax }) {
  if (mode === "off") return "off";
  if (!configured) return "not_configured";
  if (systemTurn) return "system_turn";          // 系统自己发的回合(查岗之类)不是她说的话
  if (reset) return "reset";                     // 晚安 / 归档 / 换窗口这类重置词不附
  if (String(text || "").trim().length < 2) return "too_short";
  if (windowMax > 0 && windowCount >= windowMax) return "window_full";
  return "";
}

// 还在冷却中的桶 id(顺手清掉过期的)。cooldown: Map<id, 上次递出的毫秒时间>
export function coolingIds(cooldown, now, hours) {
  const out = [];
  for (const [id, t] of cooldown) {
    if (now - t < hours * 3600e3) out.push(id);
    else cooldown.delete(id);
  }
  return out;
}

export function buildUrl(base, { q, n, exclude, minAgeH }) {
  const u = new URL(base);
  u.searchParams.set("q", String(q || "").slice(0, 2000));
  if (n) u.searchParams.set("n", String(n));
  if (minAgeH != null) u.searchParams.set("min_age_hours", String(minAgeH));
  if (exclude && exclude.length) u.searchParams.set("exclude", exclude.join(","));
  return u.toString();
}

// 递给 AI 的那一行。用法写在标注里,所以不用改人设文件。
export function formatHint(pick) {
  if (!pick || !pick.id) return "";
  const date = pick.created ? `${pick.created} ` : "";
  const name = pick.name ? `「${pick.name}」` : "";
  return `【系统·浮现】记忆库里自动翻到一件可能相关的旧事(系统附的,不是她说的;用得上就自然接住,用不上就当没看见;别提这行标注):`
    + `${date}${name}${pick.excerpt || ""}(全文:dream(detail_ids="${pick.id}"))`;
}

// 调 OB。任何失败都返回 { error },调用方照常发消息、只是不附。
export async function fetchRecall({ url, token, timeoutMs, fetchImpl = fetch }) {
  const t0 = Date.now();
  try {
    const r = await fetchImpl(url, { headers: { Authorization: `Bearer ${token}` }, signal: AbortSignal.timeout(timeoutMs) });
    if (!r.ok) return { error: `http_${r.status}`, ms: Date.now() - t0 };
    return { ...(await r.json()), ms: Date.now() - t0 };
  } catch (e) {
    return { error: e?.name === "TimeoutError" ? "timeout" : "fetch_failed", ms: Date.now() - t0 };
  }
}

// 观察记录的一条:只留她那句的开头 24 字,不带记忆正文。
export function observation({ mode, text, res, injected, skip }) {
  return {
    at: new Date().toISOString(), mode,
    preview: String(text || "").replace(/\s+/g, " ").slice(0, 24),
    skip: skip || null,
    reason: res ? (res.error || res.reason || null) : null,
    ms: res?.ms ?? null,
    pick: res?.pick ? { id: res.pick.id, name: res.pick.name, rare: res.pick.rare } : null,
    candidates: (res?.candidates || []).map((c) => ({ name: c.name, score: c.score, skip: c.skip })),
    injected: !!injected,
  };
}

export function pushRing(ring, item, max = 50) {
  ring.push(item);
  while (ring.length > max) ring.shift();
  return ring;
}
```

### 2.4 shim:`server.js` 接线(四处)

**① 顶部:变量和状态**

```js
import { recallMode, skipReason, coolingIds, buildUrl, formatHint, fetchRecall, observation, pushRing } from "./recall.mjs";

const RECALL_URL = (process.env.RECALL_URL || "").trim();          // https://<OB域名>/api/recall
const RECALL_TOKEN = (process.env.RECALL_TOKEN || "").trim();      // = OB 的 OMBRE_RECALL_TOKEN
const RECALL_CONFIGURED = !!(RECALL_URL && RECALL_TOKEN);
const RECALL_TIMEOUT_MS = +(process.env.RECALL_TIMEOUT_MS || 1500) || 1500;
const RECALL_COOLDOWN_H = +(process.env.RECALL_COOLDOWN_H || 12) || 12;
const RECALL_MAX_CHARS = +(process.env.RECALL_MAX_CHARS || 240) || 240;
const RECALL_MIN_AGE_H = +(process.env.RECALL_MIN_AGE_H ?? 24);
const RECALL_WINDOW_MAX = +(process.env.RECALL_WINDOW_MAX ?? 30);   // 0 = 不封顶
let recallModeNow = recallMode(process.env.RECALL_MODE);
let recallWindowCount = 0;
const recallCooldown = new Map();
const recallLog = [];
let recallChain = Promise.resolve();   // 保证顺序:等 OB 时后来的消息不许插队
let recallPending = 0;                 // 链上还有几条没交出去;>0 时连不问 OB 的消息也得排进链
```

**② 开新窗口、上下文被压缩时**:`recallWindowCount = 0;`(压缩后之前递的已被摘要掉,上限重新算)。

**③ 处理消息的函数**:把原来「拼好提示行 → 交给进程」的末尾**原样拆成一个 `finishMessage(req, m, res)`**,
然后在调用它之前插这段:

```js
const recallSkip = skipReason({ mode: recallModeNow, configured: RECALL_CONFIGURED, text, reset, systemTurn,
                                windowCount: recallWindowCount, windowMax: RECALL_WINDOW_MAX });
const m = { text, hints /* 你原来那些注入行 */, ...其余原样 };
if (recallSkip) {
  if (recallSkip !== "off" && recallSkip !== "system_turn") pushRing(recallLog, observation({ mode: recallModeNow, text, skip: recallSkip }));
  if (!recallPending) return finishMessage(req, m, res);       // 链上没人在等:同步走,和改动前逐字相同
  recallPending++;                                             // 有人在等 OB:排在它后面,别插队
  const job = recallChain.then(() => finishMessage(req, m, res)).finally(() => { recallPending--; });
  recallChain = job.catch(() => {});
  return;
}
recallPending++;
const job = recallChain.then(async () => {
  let line = "";
  try {
    const mode = recallModeNow;
    const url = buildUrl(RECALL_URL, { q: text, n: RECALL_MAX_CHARS, minAgeH: RECALL_MIN_AGE_H,
                                       exclude: coolingIds(recallCooldown, Date.now(), RECALL_COOLDOWN_H) });
    const r = await fetchRecall({ url, token: RECALL_TOKEN, timeoutMs: RECALL_TIMEOUT_MS });
    const hint = formatHint(r.pick);
    if (hint) {
      recallCooldown.set(r.pick.id, Date.now());   // observe 也记冷却,日志才像真开了的样子
      recallWindowCount++;
      if (mode === "on") line = hint;
    }
    pushRing(recallLog, observation({ mode, text, res: r, injected: !!line }));
  } catch (e) { console.log("[recall]", e.message); }
  finishMessage(req, { ...m, hints: line ? [...m.hints, line] : m.hints }, res);
}).finally(() => { recallPending--; });
recallChain = job.catch(() => {});
```

⚠️ 排进链的那条要是在 `finishMessage` 里抛了异常,**得自己回一个 500**(同步时框架会替你回,异步时不会,客户端会一直挂着)。

**④ 两个管理口**(带 shim 的 key):

```js
// GET  /recall?key=<SHIM_KEY>                → 现在哪一档 + 最近 50 条「这句话配了哪件旧事」
// POST /recall?key=<SHIM_KEY> {"mode":"on"}  → 改档(off / observe / on),不重启、不丢窗口;重启回到变量值
```

## 3. 测试

### 3.1 OB 单测(编的语料,别拿真记忆进仓库)

拿二三十条**编的**记忆写进临时目录,测这几类,各自单独算对错:
- **相关的该挑中**:「鼻炎又犯了」→「她的鼻炎」那条;
- **闲聊必须空手**:「今天好开心」「吃饭了没」「晚安」「你爱我吗」;
- **桥写的字不触发**:「(她发来一个贴纸)」不能翻出「贴纸」那条;
- **繁体能对上**:「海邊」能挑中「海边」;
- **只读**:调一次之后,被挑中那个桶的 `activation_count` 和 `last_active` 不变;
- **钉选 / feel / 刚存的 / 冷却中的**不挑。

### 3.2 shim 端到端(零额度)

起一个**假 OB**(固定回某个 pick,能故意慢 / 超时)和一个假 Anthropic 后端,真跑 shim + 真 CLI,验:
`off` 时完全不问 OB;`observe` 问了但没递、冷却照记;运行时切 `on` 后真递、而且**进程只 spawn 一次**(没丢窗口);
慢的那句后面紧跟一个「嗯」,「嗯」不能先到;OB 超时照常发;重置词不问;`/recall` 不带 key 回 401。

⚠️ 如果你的 e2e 脚本是「把几份 `.mjs` 拷进临时目录再跑」,**记得把 `recall.mjs` 加进拷贝清单**,
不然其余几套 e2e 会在 import 那一行直接挂掉。

### 3.3 上线前:拿真实库只读彩排(最要紧的一步)

编的语料测不出「真实标签有多散」—— 原型的第一版在编的语料上全绿,一上真实库就翻车(坑 1)。
**在 OB 容器里**写个一次性脚本:`list_all()` 读全库 → 对 30~40 句「她平时真会说的话」(一半具体的事、一半闲聊)
各调一次 `search(use_embedding=False)` + `pick()`,**只打印挑中的桶名**,不打印正文、不写任何东西。
原型的成绩:40 句里 9 句挑中、全对;31 句空手(包括「开心」「吃饭了没」「你爱我吗」「记忆库是不是又出问题了」)。

**过不了这一步就别开 `on`。**

## 4. 上线顺序、急救开关、观察口

1. OB 设 `OMBRE_RECALL_TOKEN=<随机长串>`,部署 OB(改 OB 不影响 AI 的窗口)。
   `curl -H "Authorization: Bearer <随机长串>" "https://<OB域名>/api/recall?q=鼻炎又犯了"` 能回 JSON 就通了。
2. shim 设 `RECALL_URL` / `RECALL_TOKEN`(同一个值)/ `RECALL_MODE`,部署 shim。
   ⚠️ **部署 shim 会重启常驻进程 = 丢 AI 当前的窗口**,先让她本人跟 AI 说一声归档。
3. 稳妥的做法是 `RECALL_MODE=observe` 跑一两天,`GET /recall` 看「这句话配了哪件旧事」,准了再
   `POST /recall {"mode":"on"}`(不丢窗口)。原型那边所有者拍板跳过了 observe 直接 `on` —— 前提是第 3.3 节彩排过了。

| 想干什么 | 怎么做 | 丢窗口吗 |
|---|---|---|
| 当场关掉 | `POST /recall?key=… {"mode":"off"}` | 不丢 |
| 只记不递 | `POST /recall?key=… {"mode":"observe"}` | 不丢 |
| 看最近配得准不准 | `GET /recall?key=…` | — |
| 调冷却 / 上限 / 摘录长度 | 改 `RECALL_*` 变量 + restart | **丢** |
| 往停用词表加词、调稀有门槛 | 改 OB 的 `recall.py` + 部署 OB | 不丢 |

**她说「他老提些不相干的旧事」时**:先看 `GET /recall` 是哪个词放行的(`rare` 字段),
多半是一个该进停用词表的词,加进 `STOP_WORDS` 部署 OB 就好,不用碰 shim。

## 5. 坑(每一条都是真撞过的)

1. **「常见」要按正文数,不能按标签数。** 第一版按「几个桶打了这个标签」算 —— 真实库的标签极散
   (原型 2389 个标签里 1869 个只出现过一次),按标签数「开心」和「海边」都只挂 2 个桶,根本分不开,
   于是「今天好开心呀」翻出了一件不相干的旧事。改成按正文后:「开心」50、「我们」119 vs「海边」5、「鼻炎」10,一目了然。
2. **桥写的字会被当成她说的话。** 桥把贴纸写成「(她发来一个贴纸)」,于是每发一张贴纸都凭「贴纸」翻出那件「贴纸互动」的旧事。
   查询前先洗掉(`clean_query`)。你的桥写什么格式,就照着改那几行正则。
3. **光按次数挡不住情绪词。** 「委屈」「想你」和「代码」「纪念日」出现次数一个量级,门槛挡不住,得靠停用词表。
   上线当晚她发了 4 句真实消息,翻了 3 次、都不太搭,加完停用词表之后 4 句全空手、真事照样翻对。
4. **语音转写是繁体。** ears 这类转写常输出繁体,记忆库是简体,子串一个都对不上,她用语音说的话永远翻不到。转简体用
   `opencc-python-reimplemented`(Apache-2.0),**别用 zhconv(GPL,和 MIT 仓库不兼容)**。转写本身听错的修不了。
5. **别每句多调一次 embedding。** OB 的 `search()` 默认先做向量预筛,自动浮现用不上,却让她每句话都多一次 API 调用。
   加 `use_embedding=False`。
6. **只读要有测试盯着。** 一旦哪天有人在接口里顺手 `touch` 了,就开始滚雪球(规矩 1.1)。
7. **递进去的字收不回来。** 那行进了会话历史,一行约 150 token,30 次封顶约 4500 token / 窗口。
   所以要冷却、要每窗上限,刚存 24 小时内的不递(多半还在这个窗口里),钉选的不递(awaken 已经带了全文)。
8. **乱序。** 要等 OB 的那句如果直接 `await`,她紧接着发的「嗯」会先进进程。所以要排进一条 Promise 链;
   而且链上有人在等时,**连不问 OB 的消息也要排进去**。
9. **`off` 要和没这功能时逐字相同**:不等 OB、不进链、同步走。这样出任何事,一句 `{"mode":"off"}` 就能确定回到原样。
10. **每窗第一句不计数**:新窗口第一句递完,随后 spawn 新进程时计数被清零,最多松一条。别为它去改清零时机。
11. **用法写进提示行,就不用改人设。** 「系统附的,不是她说的;用得上就接,用不上当没看见;别提这行标注」写在每行开头,
    AI 一看就懂。改人设文件通常要部署 shim、丢窗口,能不改就不改。
12. **几件都合格时,别直接取分数最高的。** `search()` 的分是时间、重要度、情绪的综合分,跟「哪件最贴她这句话」关系不大。
    真实一例:她说「人机恋博主」,三个桶都打了「人机恋」标签,一封情书比「人机恋博主态度」高 0.06 分,递出去的就是情书,
    她的感觉是「怎么乱浮现」。改成先比「桶名和她这句话重合几个字」(只算含命中稀有词的那段),一样再看分数。
    改完拿真实库重新彩排:56 句只变了 3 句、都变对了,没有多翻也没有少翻。

## 6. 可选升级:想让它也懂「换了说法」(我们没做,你自己选)

**现在这版的短板**:只认她原话里出现的具体词。她说「鼻炎又犯了」能翻到,说「老是打喷嚏」就翻不到 ——
它不知道「打喷嚏」和「鼻炎」是一回事。原型那边用编的语料量过:**换个说法,一半找不到**。

**为什么默认不用语义(向量)检索**:AI 自己调 `breath` 时也走向量,但那边一次回好几条,**AI 自己会看、不相关就不用**;
自动浮现没人把关,递什么他就看到什么。而向量分不开「真有」和「真没有」:原型真实库上量,
**库里真有的事相似度 0.65~0.81,库里根本没有的事(「她养的狗」「牙疼看牙医」)最高也到 0.69** —— 两边几乎挨着。
直接拿向量来递,她说「牙疼」也会被硬塞一件沾边的旧事。

想补这个短板,有两条路:

| | A. 加向量通道,门槛定高 | B. 候选交给小模型复核 |
|---|---|---|
| 怎么做 | 关键词没命中时,再看向量相似度;高于一条很高的线(比如 0.75)才递 | 关键词和向量各找几条候选,再让一个便宜的小模型判断「这件旧事跟她这句话真的相关吗」,相关才递(Serein 就是这么做的) |
| 准不准 | **不够准**:线定高了漏,定低了乱递,中间那条缝很窄,而且换 embedding 模型就得重量 | **最准**:有了「把关的人」 |
| 花多少 | 几乎为零(一句话几十个 token,一个月几毛钱);但每句多一次 embedding 调用,**会和 AI 平时存 / 搜记忆抢同一份免费额度** | 估每月**十几到几十元人民币**(按每天约 200 句、每次一千多 token、DeepSeek / Gemini Flash 这类小模型的常见报价估;只有翻到候选的句子才调,实际更省) |
| 慢多少 | 每句慢零点几秒 | 翻到候选的那几句慢 1~2 秒(shim 等 OB 的超时要跟着调大,原来是 1.5 秒) |
| 要改哪 | OB 的 `/api/recall`:把 `use_embedding=False` 放开,`pick()` 里给向量命中单开一条放行规则 | 同上,外加一次 LLM 调用和一段判断提示词;**复核失败就空手**,别退回直接用向量结果 |

**我们为什么都没做**:所有者嫌每月多花钱,而且现在这版「宁可少递、也不乱递」她用着够了。方案 A 便宜但不够准,也就不值得单独做。

**你要做的话,先量再选**:拿她最近几天的**真实消息**(shim 的 `GET /recall` 里就有开头 24 字),在 OB 容器里只读跑一遍
「如果加了向量,会多翻出哪些、翻得对不对」。这只花几十次 embedding 调用。多翻出来的大多是对的,再考虑 A 或 B;
「换了说法、该翻没翻」的情况本来就少的话,两个都不用做。
